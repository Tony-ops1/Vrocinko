# Vročinko

Preprosta slovenska aplikacija za spremljanje prehlada, gripe in podobnih sezonskih obolenj pri otroku.

## Prva različica

- beleženje temperature
- beleženje danega zdravila in količine
- beleženje simptomov
- samodejni čas vnosa
- časovnica bolezni
- priprava povzetka za zdravnika
- podatki ostanejo na napravi

Aplikacija ne postavlja diagnoz in ne priporoča odmerkov zdravil.
